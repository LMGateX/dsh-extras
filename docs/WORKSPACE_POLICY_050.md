### Model policy

Workspace defaults, not an unsupported every-step enforcement promise. Configure root and all descendant agents separately with exact provider/model/optional native reasoning effort ids. Null/inherit means retain native selection, not invent an effort. Workspace identity uses native registry and durable delegation provenance, not mutable cwd or path prefix; child worktree/cd does not select a different policy. Unknown identity fails closed. Ordinary root forks must not be mistaken for active delegations.

Use native agent.model.select before preparation, awaited creation/resume lifecycle and explicit accepted updates for already live agents; do not route via deprecated agent/request or change a captured pre-step selection. Cover spawn, fork seeds, deeper descendants, resident wake, cold resume and two concurrent workspaces. Human or explicit subsequent native selections remain permitted in default mode. Cold resume preserves an existing durable native session choice rather than silently reapplying a workspace default; newly created spawn/fork agents still receive their role default (including replacement of inherited seed choice). Explicit accepted policy updates/enablement may apply to already-live agents. Where provenance cannot distinguish an old inherited selection from an own choice, resumed history is conservatively preserved, never guessed. This is default selection, not enforcement. Closing a policy stops future selection; it does not silently restore/overwrite a prior durable human choice. Capture in-flight selection; future safe steps receive accepted updates. Unsupported providers/backends expose bounded unavailable diagnostics. Do not modify upstream installation or implement hidden step-loop patches.

Unlimited defaults off and warns that native always includes permanent model request failures; do not label it transient-only. Native cancellation/unload/events remain authoritative. Compaction-tool bounded retry is separate and must not be silently converted to unlimited.
