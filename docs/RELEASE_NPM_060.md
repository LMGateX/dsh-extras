## Preserved feature boundaries

Native rc.2 already waits progressing managed tree work for a root; it does not wait arbitrary owned Jobs. Goal-wait remains useful for configured Jobs and preserved stricter activation policy. Activation/replacement/native/off, the original default and external-disarm/cancellation/owner fences remain unchanged; choose native if native tree coordination is sufficient.

Native Continue generating is still an empty normal follow-up with a durable retry user-message, not exact failed-request checkpoint replay. The absent optional checkpoint UI stays quiet on stock hosts; incompatible-protocol diagnostics and failure-origin fences remain. No unofficial rc.1 companion is shipped.

Model/shared compaction keep immutable creator/workspace provenance, default-off new policies, native model selection/retention/retry authority, one canonical profile policy and one physical runtime/executor. Chime remains browser-only. Combined or distinct splits are supported; overlapping ownership fails closed.
